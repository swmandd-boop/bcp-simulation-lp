COMMON ISSUES

こんな状態になって、
いませんか？

福祉・介護の現場では、BCPの策定は進みました。しかし「策定した後」に、多くの事業所が同じ壁に突き当たっています。

✓BCPを策定してから一度も見直していない
✓BCPの内容を知っているのは管理職や担当者だけ
✓研修や訓練をどう実施すればいいかわからない
✓毎年同じ避難訓練を繰り返している
✓災害時の職員不足まで想定できていない
✓停電・断水・通信障害が同時に起きた場合を考えていない
✓誰が意思決定するのか曖昧なまま
✓BCPに書いてあることが本当に実行できるかわからない

その課題を、シミュレーションで見える化します。

SOLUTION

BCPを「作る」研修ではなく、
「使ってみる」研修です。

BCPシミュレーション研修は、BCPを「作る」「読む」研修ではありません。災害発生後の状況を疑似体験しながら、自施設のBCPを用いて、実際に機能するかを検証する実践型研修です。

正解を覚えるのではなく、「この状況なら、あなたたちの施設・事業所ではどうする？」を繰り返し問いかけます。参加者自身が考え、話し合い、自施設の課題を発見することを重視します。

そのため研修には、講義を聞くだけでは得られない、参加者自身がBCPを「見る」「読む」「想像する」「言語化する」「振り返る」体験を盛り込んでいます。

見る 読む 想像する 言語化する 振り返る

研修を通じて、次の流れをつくります。

知る→考える→判断する→話し合う→課題を発見する→BCPを見直す

HOW IT WORKS

「正しい答えを当てる」
研修ではありません。

グループごとに状況カードを引き、その状況への対応を話し合います。単純な防災クイズにはしません。問いかけるのは、いつも自施設のことです。

自施設なら、どうするか
誰が判断するか
誰が動くか
何を優先するか
必要な物品や情報はあるか
現在のBCPに記載されているか
実際に実行できる体制になっているか

単に「備蓄がありますか？」を確認するのではなく、限られた人員・物資・情報の中で、何を優先し、どのように事業を継続するのか——BCP本来の考え方を体験します。

DIFFERENCE

一般的なBCP研修との違い

一般的なBCP研修

  • BCPとは何かを講義形式で学ぶ
  • 策定のポイント・法令上の必要事項を確認する
  • 知識は増えるが、自施設の検証はしない
  • 聞いて終わり、になりやすい

災害後の状況を提示し、その場で対応を考える

  • 参加型：参加者自身が考え、判断し、話し合う
  • 自施設のBCPを用いて検証：一般論ではなく、自分たちの計画を確かめる
  • 福祉・介護現場に特化：支援を止められない事業所が前提
  • 正解を教えない：「自分たちならどう判断するか」を問う
  • BCPの弱点が見える：決まっていない・書いていない・知られていない・実行できない
  • 研修後のBCP見直しにつながる

TOOLS

VERSIONS

施設版と在宅版

事業所の形態に合わせて、2つの版をご用意しています。

施設版

入所施設など、災害発生後も施設内で利用者への支援を継続する事業所を想定。32枚の状況カードを使用します。

在宅版

地域の中でサービス提供を行う事業所を想定。地域包括支援センター・居宅介護支援事業所・通所介護が対象です。訪問系サービスは対象に含まれません。

※ 障害福祉サービスについては、施設系・通所系（生活介護、就労継続支援A型・B型など）に対応しています。

FLOW

研修のイメージ

次のサイクルを繰り返しながら、自施設の課題を掘り下げていきます。

  1. 災害発生

    災害発生後の前提状況を共有します。

  2. 状況カード提示

    グループごとにカードを引き、状況に直面します。

  3. グループで対応を検討

    自施設ならどうするか、誰が判断し誰が動くかを話し合います。

  4. 対応・判断を共有

    グループごとの判断を発表し、違いに気づきます。

  5. 講師による解説・問いかけ

    福祉現場の視点から、さらに深く問いかけます。

  6. 自施設のBCP・体制を点検

    A3「事業継続計画のポイント」40項目で現状を点検します。

  7. 改善すべき課題を整理

    研修後のBCP見直しにつなげる課題を整理します。

さらに実践を深める発展型として、「BCPファシリテーション研修」も展開しています。一度学んで終わりではなく、繰り返し考える → 動く → 見直すことで、BCPを組織に定着させます。

FAQ

よくあるご質問

管理職やBCP担当者だけでなく、一般職員も参加できますか？
はい。むしろ一般職員を含めた職員研修として実施できることが本研修の特徴です。参加型のため、一般職員もBCPを「自分ごと」として考えやすい構成になっています。
入所施設ではなく、通所系や相談系の事業所でも実施できますか？
在宅版をご用意しています。地域包括支援センター・居宅介護支援事業所・通所介護が対象です。障害福祉サービスについては、施設系・通所系（生活介護、就労継続支援A型・B型など）に対応しています。なお、訪問系サービスは現在対象に含まれません。
BCPの内容を職員がほとんど知らない状態でも大丈夫ですか？
「職員がBCPを知らない」こと自体が、本研修で扱う代表的な課題のひとつです。シミュレーションを通じて、決まっていないこと・知られていないことを可視化するところから始めます。
防災クイズやゲームのような研修ですか？
カードを使う参加型研修ですが、正解を当てるクイズではありません。「自施設ならどう判断するか」を参加者同士で話し合い、自施設のBCPや事業継続体制の弱点を発見することが目的です。
実施時間・人数・料金について教えてください。
施設・事業所の状況やご希望に応じてご提案します。まずはお気軽にお問い合わせください。
